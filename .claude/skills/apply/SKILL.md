# Черновики откликов

Номера — из последней сводки `collect`; ссылки и id тоже подходят. Отклик
не отправляешь: черновик готов — дальше решает владелец.

По каждой вакансии:

1. **Текст.** Нет полного текста — `vacancies fetch <id>`. Прочитай
   `vacancies show <id>`. Отметь `vacancies status <id> selected`.
   Если `fetch` или `show` говорит, что вакансия в архиве или удалена, —
   `vacancies status <id> closed` и скажи об этом владельцу.

2. **Опора.** Прочитай `me/profile.md`, `me/resumes/`, `me/strategy.md`.
   Письма, которые владелец назвал удачными, помечены строкой `Образец: да`
   в начале `draft.md` (`grep -l "^Образец: да" me/applications/*/draft.md`) —
   держись их тона.

3. **Черновик.** `me/applications/<id>-<компания-латиницей>/draft.md`,
   например `me/applications/123456-yandex/draft.md`. Разделы:

   - **Резюме** — какое из `me/resumes/` и почему, одной-двумя фразами.
   - **Письмо** — обычный текст для поля hh, без markdown, до ~1200 знаков:
     зачем пишу (что зацепило в вакансии) → 2–3 доказательства с цифрами
     и ссылками из резюме → чем буду полезен здесь. Без штампов («ваша
     компания — лидер», «я коммуникабелен»), без воды, факты только из
     резюме и профиля.
   - **Вопросы работодателя** — если есть в вакансии: вопрос и ответ.
   - **Тестовое** — если есть: что просят и срок.

4. **Статус.** Черновик готов — `vacancies status <id> drafted`.
   Есть тестовое — `vacancies status <id> test --test "что просят" --due ГГГГ-ММ-ДД`
   (срок, если указан).

В конце — список папок с черновиками и что проверить руками. Владелец
правит, отправляет сам и говорит «откликнулся» — тогда `applied`.
Понравилось письмо — спроси, можно ли считать его образцом; если да,
добавь первой строкой `draft.md`: `Образец: да`.
