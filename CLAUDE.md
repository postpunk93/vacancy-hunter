# job-hunter

Поиск работы на hh.ru целиком в разговоре с Claude. Владелец рассказывает
о себе и что ищет, Claude собирает вакансии, оценивает их по профилю, готовит
черновики откликов и донастраивает критерии. Отклик отправляет владелец сам.

## Этапы

| Этап | Когда | Skill |
|---|---|---|
| Настройка | нет `me/profile.md` или «давай настроим» | `setup` |
| Сбор и оценка | «собери свежие», «что нового» | `collect` |
| Черновики откликов | «черновики по 2, 5, 7» | `apply` |
| Донастройка | «слишком много X», «подними порог» | `tune` |

Нет `me/profile.md` — первый запуск: начинай с `setup`, до него другой работы
не делай. В начале разговора хук печатает `vacancies todo`: если там есть
напоминания (тестовое со сроком, черновик без отклика, отклик без ответа),
скажи о них одной-двумя строками.

## Правила

- **Вердикты ставит владелец.** Предлагай «подходит / нет, потому что…»;
  `vacancies mark` — только после его явного ответа.
- **Отклик не отправляешь.** Ничего не делаешь перед работодателем от имени
  владельца. Черновик готов — дальше решает он.
- **Код выхода 3 — блокировка или капча hh.** Остановись, скажи владельцу,
  не повторяй. Повтор — только по его команде и не раньше чем через час.
- Полный текст качай выборками, не больше ~40 вакансий за один `fetch`.
  Сначала отсекай по метаданным.
- Статусы воронки меняешь со слов владельца: «откликнулся» → `applied`,
  «позвали» → `invited`, «отказ» → `rejected`, «не буду» → `skipped`.
- xlsx (`vacancies export`) — только по просьбе.

## Статистика

«Покажи статистику», «что за сегодня», «сколько откликов без ответа» —
отвечай через `vacancies sql` по примерам из справочника ниже. Порог бери
из `scoring.threshold` в `me/config.yaml`. Ответ — коротко и словами:
«Сегодня собрано 120, оценено 45, порог прошли 8», без таблиц, если о них
не просили.

## Где что лежит

Всё личное — в `me/`, папка целиком в `.gitignore`:

- `me/profile.md` — кто я, что ищу, красные флаги; по нему идёт оценка.
- `me/strategy.md` — позиционирование, что сделать до откликов, очередь.
- `me/config.yaml` — поисковые запросы и настройки оценки.
- `me/resumes/<роль>.md` — резюме под роль.
- `me/applications/<id>-<компания>/draft.md` — черновики откликов; строка
  `Образец: да` в начале — письмо, которое владелец назвал удачным.
- `me/job-hunter.db` — база: вакансии, оценки, вердикты, воронка.
- `me/.env`, `me/logs/`, `me/exports/` — секреты Телеграма, логи, выгрузки.

Шаблоны для `profile.md` и `strategy.md` — в `templates/`, пример конфига —
`config.example.yaml`. В корень проекта личное не клади.
